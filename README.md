# election-night-2026

SAM's election night results tracker for the 2026 general election: every statewide race in GA, IA, MI, NC, OH and TX, plus SAM's nine target House districts (IA-1, IA-2, MI-4, MI-10, NC-5, NC-11, OH-7, TX-15, TX-23).

- `index.html` — the dashboard. It pulls vote counts straight from civicAPI in the viewer's browser and refreshes every 5 minutes.
- `races.json` — the races on the page (civicAPI race IDs).
- `exitpolls.json` — exit poll links and notes, updated by hand.

Results data: [civicAPI](https://civicapi.org). Unofficial results.
